# Secret Santa Game

## Overview

This project automates the process of assigning secret children to employees for the Secret Santa event at Acme company.

## Installation

1. Clone the repository.
2. Run `npm install` to install dependencies.

## Usage

1. Place the employee data in `input/employees.csv`.
2. Place the previous year's assignments in `input/previous_assignments.csv` (if available).
3. Run `node src/index.js`.
4. The output will be generated in `output/assignments.csv`.

## Testing

Run `npm test` to execute the test cases.
